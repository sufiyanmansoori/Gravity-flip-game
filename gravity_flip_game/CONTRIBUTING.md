# Contributing to Gravity Flip

Thanks for considering contributing to this project.

## Development Workflow

1. Create a feature branch from the main branch.
2. Keep changes focused and minimal.
3. Write or update tests for behavioral changes.
4. Run relevant Flutter tests before opening a PR.
5. Update documentation when public behavior changes.

## Coding Standards

- Keep code readable and production-oriented.
- Prefer small, composable functions.
- Follow the existing architecture patterns.
- Avoid introducing dead code or unused files.

## Testing

Run:

```bash
flutter test
```

Keep tests deterministic and independent.

## Pull Requests

Please keep PR titles clear and include a short summary of the work, validation performed, and any risk notes.

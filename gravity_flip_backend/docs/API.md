# API

Base URL: `/api/v1/`

Interactive documentation is available at `/api/docs/`; the OpenAPI document is available at `/api/schema/`.

## Main domains

- `/auth/` authentication and token rotation
- `/game/` real-time game lifecycle and snapshots
- `/levels/` published level catalog
- `/scores/` score submission and leaderboards
- `/achievements/` achievement unlocks
- `/user/` profile and user statistics
- `/payment/` payment and webhook endpoints
- `/notification/` notifications and read state
- `/shop/` products, carts, and checkout
- `/analytics/` event ingestion and reports
- `/admin/` staff-only control plane
